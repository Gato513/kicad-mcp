# Evidencia histórica del piloto multiagente S47–S48

Este directorio conserva los contratos, paquetes, revisiones, resultados y
manifiestos producidos durante S47–S48. Es evidencia histórica y probatoria;
no define el flujo operativo vigente ni debe usarse como plantilla para
trabajos nuevos.

Autoridades vigentes:

- `AGENTS.md` para coordinación institucional.
- `docs/proceso/FLUJO-HIBRIDO-MULTIAGENTE-v2.md` para operación detallada.

## Integridad y estructura

`archivos_temporales_contrato/` fue migrado como un árbol completo desde su
custodia externa original. Los archivos custodiados no se editaron y sus
manifiestos no se regeneraron. Las rutas absolutas que aparecen dentro de los
artefactos documentan el entorno histórico donde fueron producidos; no son
dependencias del flujo actual.

Para comprobar las unidades que incluyen manifiesto, ejecutar
`sha256sum -c MANIFEST.sha256` desde el directorio de cada unidad.
